# Changelog

All notable changes to the **CSS Variable Mapper** extension will be documented in this file.

## [1.0.0] - 2026-02-12

### Initial Release
- **Custom Configuration**: Added support for `.cssmapperconfig` file to define your color mappings.
- **Color Decorators**: Enabled real-time color gutter icons for CSS variables in the editor.
- **Smart Autocomplete**: Implemented `#` trigger for instant color-to-variable suggestions.
- **Hot Reloading**: Integrated a file watcher to update the palette and decorators instantly when the config file changes.
